## Geometry checks added

`tests/design/phone-geometry.mjs` runs in the built browser page through
`tests/design/review-built.mjs`. Every failure names its rule and requirement ID.

1. **DS21:** three collapsed rows and total above the portrait action bar;
   at least 48 px of map visible on 390×844 reveal one; split-view total visible;
   every landscape row can actually scroll fully above the action bar; difficulty
   question and all three chips on one line.
2. **DS31:** score-result text ranges stay inside their row and outside the
   points column; no ellipsis or horizontal clipping.
3. **DS22:** no visible map button overlaps a fitted pin or answer label; labels
   stay in the map; controls fit above the legend; split-view legend remains
   above the action bar.
4. **DS19 / DS4:** short-phone photo shares remain at least 39% for Kept/Made
   and 29% for When; fallback city labels remain present and non-overlapping
   in world and zoomed captures.
5. **DS34:** tour card stays inside 12 px viewport gutters; map/photo steps do
   not overlap their target, including the two previously failing sizes.

The capture matrix adds 390×664, a zoomed Kept view and a feedback-answered
reveal at every size. Collapsed captures reset scrolling and park the pointer
away from score hover targets. Captures wait for MapLibre's canvas to catch up
with its resized host before checking pins after feedback changes.

Ten new offline unit checks cover DOM order, fit clearance, tiny-host padding,
rank filtering, collision gutters, tour sizing/placement and future-year copy.
Existing colour and contrast checks remain unchanged.

## Remaining acceptance and debt

1. **P1 acceptance gate:** run E2E and the built review after integration;
   inspect actual PNGs at all five sizes, especially 375×667/390×844 collapsed
   reveals, 844×390 with feedback, and 1280×800. Geometry passing is not visual
   approval. Confirm expanded rows, total focus and Next remain usable.
2. **P2 acceptance gate:** inspect real vector tiles as well as the bundled map;
   check map fit before/after feedback, World reset, labels after zoom, tour
   keyboard use, enlarged text and reduced motion. The automatic capture
   matrix is reduced-motion and blocks external tiles.
3. **P2 layout trade-off:** all score rows are not promised simultaneously
   visible at 844×390. The compact header and total must be visible; rows are
   deliberately scrollable rather than reduced below readable/touch sizes.
4. **P3 visual debt:** tiny countries can remain obscured by pins at world scale;
   attribution and legend can still wrap. These do not justify moving answer
   coordinates, suppressing attribution or introducing misleading area marks.

Start integration verification with `npm run test:e2e`, then run
`npm run build && npm run design:review:built` and inspect the resulting PNGs.
