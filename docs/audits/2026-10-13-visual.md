## Changes and source-confirmed rationale

1. **Identity and artwork:** linked Made/Kept wordmark with real text; common
   SVG favicon source and two committed resvg PNG sizes; build-only share PNG
   with the real, whole credited photo. Mini map now has Natural Earth land,
   semantic glyphs, token colours and shortest-longitude recentering.
2. **When spacing:** phone controls start one spacing token below the photo,
   instead of centring the short controls in a tall answer region. Desktop
   retains centred controls. No photo crop or answer-state change.
3. **Focus and diagnosis rail:** the reveal score now has a padded, subtly
   rounded catalogue cell; its visible 3px focus ring and 2px offset remain.
   Test mode reserves a 44px top rail and subtracts it from round/reveal
   height, rather than floating a small badge over answers. The badge's
   inset light focus ring contrasts with the dark diagnostic rail.
4. **Overlays and recovery:** an open dialog uses a bounded flex column so
   only its body scrolls and its close/header remains available. List spacing
   uses tokens; confirmation actions can wrap. Error headings use the display
   scale and long technical references wrap instead of forcing overflow.
5. **Landscape cascade:** the short-phone rule also matched 844×390 and
   replaced the landscape grid's row tracks. It now explicitly requires
   portrait orientation, preserving the specified 55:45 landscape layout.

These are source-confirmed fixes, not claims of a completed browser audit.
Existing tokens, classes, `data-test` and `data-screen` contracts remain.
No token names or values changed. No dependency was added.
